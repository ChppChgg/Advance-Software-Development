# Horizon Cinema System

## Installation

Please begin by looking at requirements.txt to find what modules you'll need to install.

## Setup

Run `TkinterMain.py` whilst being in the Advance-Software-Development folder.

## Usage Instructions

### Staff Account
1. Log into the system using the credentials above OR Press the sign up button and create an account 
3. Click on the movie list to view your options.
4. Click on book tickets, and enter your cinema, film, date, time, amount of tickets, type of seat, and some personal information.
5. Then go on my bookings, click refresh.
6. You can then view bookings made under this staff account, you may also cancel them.

### Admin Account
1. Log in using Admin credentials above.
2. Functions available:
   - Screenings: 
        - Add a new screening
        - Edit an existing screening
        - Delete a screening
   - Films 
        - Add a new film
        - Edit an existing film
        - Delete a film
   - Reports
        - View data Booking Revenue, Popular Films, and Cinema Performance
        - Export data onto device
3. When refreshing on "Booking" Page, can also view all bookings across all cinemas.

### Manager Account
1. Log in using Manager credentials above.
2. Functions available:
    - Add or Remove film listings
    - View Users on application
3. Access to Admin Panel aswell.
